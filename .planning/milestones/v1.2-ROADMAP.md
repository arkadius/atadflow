## Milestone Summary

**Key Decisions:**
- Bitnami PostgreSQL 18.3.0 as Helm subchart (HTTPS repo, not OCI)
- Kubeflow Spark Operator for K8s integration testing (stable CRDs)
- kubectl port-forward over Fabric8 LocalPortForward (reliability)
- busybox init container for PostgreSQL readiness
- External k3d cluster for integration testing (not Testcontainers)

**Issues Resolved:**
- .helmignore excluded charts/ and tests/ directories
- Wrong PostgreSQL secret key (postgres-password vs password)
- App CrashLoopBackOff before PostgreSQL ready
- Fabric8 port-forward NoHttpResponseException
- SparkApplication API version mismatch (Phase 4 → Phase 5 fix)

**Tech Debt Incurred:**
- Spark Operator not added as Helm chart dependency (installed dynamically in test instead)
- Phase 2 recommended Apache Spark K8s Operator but Phase 5 used Kubeflow Spark Operator
