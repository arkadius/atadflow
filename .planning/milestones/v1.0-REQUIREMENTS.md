## v1 Requirements

Requirements for milestone v1.0 — Minimal Spark Execution.

### Infrastructure

- [x] **INFRA-01**: Spark Connect server runs in Docker Compose with correct port exposure (15002, 4040)
- [x] **INFRA-02**: CodeGenerationService generates PySpark code using `SparkSession.builder.remote("sc://...")` for Spark Connect
- [x] **INFRA-03**: Backend verifies Python and PySpark availability on startup and reports clear error if missing

### Submission

- [x] **SUB-01**: User can submit a flow and backend executes generated PySpark code as async Python subprocess
- [x] **SUB-02**: Backend writes generated PySpark code to temp file and cleans up after execution completes or fails

### Lifecycle

- [x] **LIFE-01**: User can see job status transition from PENDING to RUNNING to COMPLETED or FAILED
- [x] **LIFE-02**: User can cancel a running job which kills the Python subprocess
- [x] **LIFE-03**: Frontend polls job status every 5 seconds for active jobs and stops polling when terminal
