<task type="auto">
  <name>Add Spark Connect service to Docker Compose</name>
  <files>docker-compose.yml</files>
  <action>
Add a new service named `spark-connect` to docker-compose.yml using the apache/spark:4.0.2 image.

Configuration:
- Image: `apache/spark:4.0.2`
- Container name: `atadflow-spark-connect`
- Command: `/opt/spark/sbin/start-connect-server.sh --packages org.apache.spark:spark-connect_2.13:4.0.2`
- Ports:
  - `15002:15002` (Spark Connect gRPC server)
  - `4040:4040` (Spark UI)
- Environment variables:
  - `SPARK_NO_DAEMONIZE=true` (keeps container running)

The start-connect-server.sh script is the standard way to launch Spark Connect server in the official Spark Docker image.
  </action>
  <verify>
Run `docker compose up -d spark-connect` and verify:
1. Container starts: `docker ps | grep spark-connect`
2. Logs show "Spark Connect server started": `docker logs atadflow-spark-connect`
3. Port 15002 is listening: `netstat -tuln | grep 15002` or `docker compose ps`
  </verify>
  <done>
- docker-compose.yml contains spark-connect service with apache/spark:4.0.2 image
- Ports 15002 and 4040 are exposed
- Container starts successfully and logs confirm server is running
  </done>
</task>

  </done>
